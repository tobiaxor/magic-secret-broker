# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Before reporting, read the *Security model* section of the [README](README.md): an agent running arbitrary commands as the same Windows user is outside what secret-broker can defend against, and the listed limitations are known. Reports that show a mistaken (not malicious) agent getting a secret without approval, a notification or an audit entry are in scope.
